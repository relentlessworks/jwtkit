jwtkit

Agentic-first JWT creation, verification, and decoding service

Go Single Binary Zero Deps MCP Multi-tenant

An agentic-first service for creating, signing, verifying, and decoding JSON Web Tokens. Designed for AI agents to drive over plain HTTP — no UI, no SDK, just clean text APIs.

Features

  • JWT Creation/Signing — HS256/384/512 (HMAC) and RS256/384/512 (RSA) algorithms
  • JWT Verification — Signature validation with exp/nbf claim checks
  • JWT Decoding — Decode header and payload without signature verification
  • Key Management — Create, list, get, delete keys with workspace scoping
  • OTP Auth — Email → code → long-lived bearer token
  • Multi-tenant — Workspaces, plans, limits, audit logs
  • MCP Connector — JSON-RPC 2.0 at /mcp
  • Self-documenting — GET /help returns a one-page operating manual
  • Plain text by default — JSON on demand via ?format=json
  • Instructive errors — Every 4xx includes a hint for agent self-correction

Quick Start

# Start the service
./jwtkit

# Read the operating manual
curl http://localhost:8080/help

# Request OTP
curl -X POST http://localhost:8080/auth/otp -d 'email=agent@example.com'

# Verify OTP and get token
curl -X POST http://localhost:8080/auth/verify -d 'email=agent@example.com&code=123456'

# Create a workspace
curl -X POST http://localhost:8080/workspaces -H 'Authorization: Bearer TOKEN' -d 'name=my-jwt-service'

# Create an HMAC key
curl -X POST http://localhost:8080/keys -H 'Authorization: Bearer TOKEN' -d 'algorithm=HS256'

# Sign a JWT
curl -X POST http://localhost:8080/jwt/sign -H 'Authorization: Bearer TOKEN' -d 'key=key_a1b2c3&claims={"sub":"user123","role":"admin"}'

# Verify a JWT
curl -X POST http://localhost:8080/jwt/verify -H 'Authorization: Bearer TOKEN' -d 'key=key_a1b2c3&token=eyJhbGci...'

# Decode a JWT (no signature check)
curl -X POST http://localhost:8080/jwt/decode -d 'token=eyJhbGci...'

Supported Algorithms

  • HMAC: HS256, HS384, HS512
  • RSA: RS256, RS384, RS512

Endpoints

GET  /help              — Operating manual
GET  /.well-known/agent.md — Agent instructions
POST /auth/otp           — Request OTP code
POST /auth/verify        — Verify OTP, get bearer token
GET  /workspaces         — List workspaces
POST /workspaces         — Create workspace
GET  /keys               — List keys
POST /keys               — Create key
GET  /keys/:handle       — Get key details
DELETE /keys/:handle     — Delete key
POST /jwt/sign           — Sign and create a JWT
POST /jwt/verify         — Verify a JWT
POST /jwt/decode         — Decode a JWT (no signature check)
POST /mcp                — MCP JSON-RPC 2.0 endpoint
